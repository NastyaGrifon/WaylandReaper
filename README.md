# WaylandReaper

> [!WARNING]
> **⚠️ AI GENERATED CODE ⚠️**
> The `extension/` backend was generated by an **AI assistant** (Monika /
> Hermes Agent) at the request of Nastya Grifon. Reviewed and tested on
> GNOME Shell 50.4 (Wayland, Arch), but review before production use.

Force-close the focused window on GNOME **Wayland** — the `kill -9 $(xprop …)`
equivalent that X11 had and Wayland deliberately took away.

Since v2 WaylandReaper is a **pure GNOME Shell extension**: no script, no
DBus backend dependency, nothing third-party. Install it and it just works.

## How it works

```
Super+Q / Alt+F4  ──►  extension.js (inside gnome-shell)
                         │ global.display.get_focus_window()
                         ├─ pid = win.get_pid()
                         ├─ comm = /proc/<pid>/comm
                         ├─ whitelist match? → skip
                         └─ SIGTERM → grace period → SIGKILL (if still alive)
```

No special privileges are required: gnome-shell runs as your user, and
`kill` on your own processes is always allowed.

## Install

```bash
git clone https://github.com/nastyagrifon/WaylandReaper.git
cd WaylandReaper
mkdir -p ~/.local/share/gnome-shell/extensions/waylandreaper-backend@nastyagrifon.me
cp -r extension/* ~/.local/share/gnome-shell/extensions/waylandreaper-backend@nastyagrifon.me/
glib-compile-schemas ~/.local/share/gnome-shell/extensions/waylandreaper-backend@nastyagrifon.me/schemas/
```

Log out and back in (Wayland does not rescan extensions at runtime), then:

```bash
gnome-extensions enable waylandreaper-backend@nastyagrifon.me
```

## Settings

Open *Extensions → WaylandReaper → preferences*:

| Setting | Default | Notes |
|---|---|---|
| Super + Q | on | primary kill hotkey |
| Alt + F4 | off | opt-in: replaces the polite window close |
| Whitelist | gnome-shell, ddterm, yakuake, guake, kitty, alacritty | exact `/proc/PID/comm` match, editable |
| Grace period | 500 ms | SIGTERM → SIGKILL delay |
| Notifications | off | opt-in per-kill toasts |

## Known limitations

- Kills the whole **process**, not a single window: closing one Firefox
  window closes all of them (they share a PID).
- Flatpak apps may report a portal proxy PID instead of the app itself;
  if a Flatpak app survives the hotkey, add its real `comm` to the whitelist.
- Kernel truncates `comm` to 15 characters.
